# Memoria de Claude Code

Copia de la memoria automática que Claude Code guarda de este proyecto. El original vive fuera del repo, en `~/.claude/projects/<proyecto>/memory/`, y es el que Claude Code lee y escribe; esta carpeta es una **instantánea** para que la memoria quede commiteada, como pide la entrega.

Se refresca con el comando `/sincronizar-memoria`. No se edita a mano: un cambio aquí no llega al original y se pierde en la siguiente sincronización.

`MEMORY.md` es el índice, una línea por memoria. Cada fichero guarda un hecho con su tipo:

| Tipo | Qué guarda |
| --- | --- |
| `feedback` | Cómo prefiere trabajar el autor, con el porqué |
| `project` | Decisiones e ideas del proyecto que no se deducen del código |
| `reference` | Dónde está algo fuera del repo |
